Entering it on the machine

        
    
          
  1. Mode switch to Pattern Write, sequencer stopped. Clear the slot with
            CLEAR+# — it resets to an empty 16-step pattern.
    2. 
          
  2. Set the length to 64: FUNC+LENGTH, PAGE to the
            fourth page, then 16.
    3. 
          
  3. Start the sequencer. Set the Track/Instrument switch to one voice and punch
            its 64 steps — use Isolate above to show that voice alone, four groups of 16,
            one group per PAGE press.
    4. 
          
  4. Accents: ACCENT then the steps. Flam and roll the same way with
            FLAM and ROLL, or hold the modifier and press the steps.
    5. 
          
  5. The ACC* row is the Global Accent lane — FUNC+ACCENT,
            then those steps. It accents every voice that has a hit there.
    6. 
          
  6. Voice settings on the left are Tone / Nuance / Inst Select positions. The CC number
            beside each one sets it over MIDI instead.
    7. 
        

      

    


    
Note numbers and CC assignments are from the RezOSDrum v1.0 MIDI
      implementation charts. Velocity ≥ 112 is read as an accented strike, so these patterns
      play with their accents intact straight from a DAW — the matching MIDI files are in
      out/midi/. Twelve TT-606 and thirteen TT-78 patterns repeat all four bars
      on purpose: motorik, EBM and the polyrhythm studies, where the phasing is the point.
